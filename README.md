# esp32-tetris-theme

Plays the Tetris Theme (Korobeiniki) on an ESP32-S3 using a buzzer on Pin 4.

## Hardware
- ESP32-S3
- Buzzer/Speaker on Pin 4 (via 100–330Ω resistor recommended)
- GND on GND

## Usage
Flash with Arduino IDE or PlatformIO.
